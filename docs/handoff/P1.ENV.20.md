# Handoff: P1.ENV.20 (novi javni repo) + P1.ENV.15 (zaštita `main`)

> Zapis migracije od 2026-11-26. Puna verzija s komandama, skriptom za provjeru i fajlom za zamjenu teksta je u privatnom repou `lejliczijad-private` (`handoff/P1.ENV.20/`), jer sadrži privatne podatke.

## Zašto novi repo, a ne force push u postojeći
GitHub zauvijek čuva `refs/pull/<N>/head` za stare PR-ove, a oni sadrže commitove s ITF fontovima i internim podacima. Te refove može obrisati samo GitHub Support. Novi repo ih nema. Stari repo je privatna, arhivirana `ZijadLejlic/lejliczijad-portfolio-archive` i čuva PR-ove 1–40 s komentarima.

## Šta je urađeno
1. Stari repo je preimenovan u `lejliczijad-portfolio-archive`; secreti su obrisani, repo je arhiviran (read-only).
2. Historija je prepisana `git filter-repo`-om u svježoj kopiji:
   - `content/intake/**` je uklonjen iz svakog commita (P1.ENV.21; sadržaj je u `lejliczijad-private`);
   - stara tech.md §11 i red o satnici u prd.md dnevniku odluka su u svakom commitu zamijenjeni verzijom bez brojki;
   - 4 ITF font fajla (`ClashDisplay-*.woff2`, `Satoshi-*.woff2`) su uklonjena iz svakog commita (ADR-017);
   - autor commitova je prebačen na GitHub noreply adresu;
   - `(#N)` i `Merge pull request #N` u porukama su postali `(archive PR N)` i `Merge archive PR N`, da brojevi ne linkuju na pogrešne PR-ove u novom repou.
3. Provjere prije objave: 0 ITF fontova (po imenu i po SHA-256), 0 fajlova iz `content/intake/`, 0 blobova s cijenama, 0 privatnih email adresa, gitleaks "no leaks found", stablo identično starom `main`. Kontrola istom skriptom nad starom historijom je nalazila pogotke, pa skripta radi.
4. Novi javni repo je podešen prije prvog pusha: secreti `CLOUDFLARE_ACCOUNT_ID` i `CLOUDFLARE_API_TOKEN` (novi token, isti opseg), varijabla `CODEQL_ENABLED=true`, environment `production`, secret scanning s push protectionom, vulnerability alerts, private vulnerability reporting, delete-branch-on-merge.
5. Push: `main` = `a4e7970` (66 commitova). CI i Security su zeleni; produkcijski deploy namjerno pada na content guardu (`TODO(content)`, P1.HOME.01).
6. Ruleset "Protect main" (id 28164632) je primijenjen iz [`.github/rulesets/main.json`](../../.github/rulesets/main.json). Direktan push na `main` je odbijen (GH013).

## Posljedice

- Lokalni folder koji ima staru historiju se više ne pusha na `main`; radi se samo na granama od novog `origin/main`.
